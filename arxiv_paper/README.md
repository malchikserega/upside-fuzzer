# arXiv Paper Materials for UpsideFuzz

This directory contains the initial structural documents for preparing a research/tool paper about the UpsideFuzz (Void) framework.

## Contents
- `PLAN.md`: The 5-week publication strategy, timeline, and execution plan.
- `SKETCH.md`: The structural outline, abstract, and draft of the paper's contents.

## Goal
To formalize the novel approaches developed in this repository (specifically, the Semantic Source-Aware Grammar Enhancement combined with SHM coverage-guided execution) into an academic format suitable for publication on arXiv or major cybersecurity/software engineering conferences.
